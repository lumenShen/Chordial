# Chordial UI 设计规格（Studio Neutral）

> 方向评审：Studio Neutral（采用）、Night Listening、Editorial Hi-Fi、Pro Console。
> 最终选择 Studio Neutral：最接近 EffiBuddy_GPUI 的克制语言，也最适合长时间听歌。
>
> 设计方向：EffiBuddy_GPUI 式的中性工作台 + 音乐软件的信息结构。
> 目标不是“炫酷播放器”，而是可以每天打开、连续使用数小时的桌面音乐工具。
> 本文件是 `crates/chordal-ui` 的实现依据。

## 1. 设计原则

1. **中性底色，单一墨色强调**：深色近黑、浅色纸白；强调色只用于播放态、进度、选中、焦点。
2. **hairline 分层**：用 1px 边框和 4 阶明度建立层次；唯一例外是底部悬浮 Dock 的半透明材质。
3. **列表优先**：曲目表是主角；行高固定 52，虚拟列表滚动，行内只放小尺寸占位封面。
4. **静态界面，动态声音**：除播放指示、歌词、进度、加载、沉浸层控件的一次性动效外不做循环动画；面板内 hover 即时换色。
5. **三栏 + 悬浮 Dock**：侧栏 232、曲目板 352、正在播放自适应；播放控制离开页面布局，成为悬浮在窗口底部的 Dock。

## 3. 字体

- 家族：`Noto Sans CJK SC`（由 fontconfig 做拉丁/符号回退）。
- 字号：页面标题 20/600，区块 13/500，正文 13/400，元信息 11/400，时间码 11/400。

### 4.1 断点与手机壳

断点只在 `responsive.rs` 定义，所有页面共用同一判据：

| 宽度 | 模式 | 组件关系 |
| --- | --- | --- |
| ≥ 1020 | Wide | 侧栏 + 曲目板 + 右栏 + Dock |
| 720–1019 | Medium | 侧栏 + 曲目板（填满），右栏与标题栏状态消息隐藏，Dock 保留 |
| < 720 | Phone | 单列手机壳：无侧栏、无曲目板并排、无 Dock |

手机壳有三页：

- **播放页**：沿用竖屏沉浸层的 `amll_player_column`（封面 / 信息 / 进度 /
  传输 / 音量），顶部是同一条 50×8 pill + 窗口红绿灯，底部是全屏 /
  曲库 / 队列 / 歌词。背景复用封面驱动的 Mesh，没有封面时用近黑蓝底。
  封面本身可点，直接打开歌词页。
- **歌词页**：全屏 Mesh + 可滚动、可点击 seek 的歌词；标题栏叠加在顶部
  （红绿灯 / 返回播放 / 当前曲名 / 菜单）。歌词字号按窗口宽度缩放
  （18–34px），当前行高亮、邻行模糊；没有歌词时显示 `lyrics_status`
  或「暂无歌词」。返回键 / Esc 回到播放页。
- **曲库页**：桌面曲目板铺满窗口（本地库 / 队列 / 搜索结果 / 集合），
  页头提供「返回播放」，搜索框、行点击与播放全部保持原行为；选中曲目
  后自动回到播放页。

状态收敛规则：

- 收窄到 Phone 时保留「搜索 / 集合 / 队列」的浏览上下文；只有普通曲库
  且有当前曲目时才落到播放页；没有曲目则落到曲库页。
- 离开 Phone 时关闭手机抽屉并把 `lyric_view` 从 Mesh 交还给面板样式；
  手机播放页（文字隐藏）与歌词页（文字可见）和沉浸层共用同一个视图，
  因此用 `PhoneBackdrop::{Off,Player,Lyrics}` 做一次性迁移，主题切换
  与「歌词扫光宽度」变更后都会重新套用对应样式。
- 沉浸层的「左播放列 + 右歌词」额外要求宽度 ≥ 820（避免 700px 宽时
  硬拆两列）；否则走竖向/单列布局。
- 设置中心：窗口装不下 800×600 卡片（宽 < 848 或高 < 648）时改为整窗
  设置页，左导航变成顶部横向分段；登录卡片宽度收敛到窗口内。
- 手机抽屉（标题栏菜单 / 曲目信息「…」）承载正在播放、歌词、所有音乐、
  搜索、设置、主题与原有的睡眠/均衡器/队列入口。

标题栏：左侧红/黄/绿交通灯（关闭 / 最小化 / 缩放）→ 中间拖拽区与品牌（音符 + 12.5/600「Chordial」）→ 状态消息 → 主题切换。系统标题栏隐藏（`appears_transparent`），窗口靠自绘交通灯与 6px 边缘热区缩放。拖动热区按平台实现：Linux 走 gpui 的 `start_window_move`（compositor move 请求）；Windows 的 `start_window_move` 是空实现，热区标记为 `WindowControlArea::Drag`，由 `WM_NCHITTEST → HTCAPTION` 交给 DefWindowProc 原生拖动（含贴边分屏与双击最大化）。

## 5. 左侧导航

- **音乐**：所有音乐（本地库全量）、播放队列（当前队列），行尾显示数量。
- **音乐源 · ROUTER**：全部音源 + 每个已注册源；点击进入搜索并路由到该源，行尾小按钮负责加载/卸载，状态点承担加载状态。
- **播放模式**：顺序播放 / 随机播放 / 单曲循环；当前模式用 accent 文字 + 对勾。
- 底部固定「本地库」卡片：曲目数 / 音源加载数 / Ctrl K 提示。
- 点击“所有音乐 / 播放队列”切换列表；加载/卸载按钮不触发路由（`stop_propagation`）。

## 6. 曲目板（中间栏）

列：序号/电平 18 · 占位封面 34 · 标题 flex · 时长 40（右对齐）。

- 行高 52，圆角 7；hover 只换底色，无分隔线。
- 当前行：中性灰 `selection` 底 + 序号列换成 3 根 2px 电平条（`playing` 蓝，界面上仅存的蓝）；标题保持墨色。
- 标题 12.5/500，副行 10.5/faint；副行 = 艺人 · 专辑（搜索页为 艺人 · 音源）。
- 顶部：面板标题（17/600）+ 副标题（结果数 / 聚合耗时 / 路由）+ 播放全部图标钮（hover 才显形）；下方是常驻搜索框。
- 点击整行播放，并把当前可见列表设为队列；少于 1020 宽时曲目板伸展占满右栏空间。

## 7. 悬浮 Dock

播放控制不再是全宽底栏，而是浮在窗口底部中央的独立 Dock：

- 位置：`bottom 14`、水平居中、宽 `min(窗口 - 32, 840)`、高 72、圆角 18。
- 材质：`glass` 半透明填充 + hairline 描边 + 30px 软阴影；它是界面里唯一使用玻璃材质的元素。
- 左 232：42 封面（无封面用音符占位）+ 曲名 12.5/500 + 艺人 10.5/faint，点击进入沉浸歌词。
- 中：上一首 28 / 播放 36 圆形墨色（`accent` = ink）/ 下一首 28。
- 进度：当前时间 36 + 连续滑杆 + 总时长 36；填充用墨色，点击/拖动 seek。
- 右：音量图标 + 72 滑杆（窗口 ≥ 1120 时显示）+ 1px 分隔 + 歌词入口。
- 曲目板与右栏在底部预留 84–100px，保证最后一行不会被 Dock 盖住。
- 禁止 40 段进度条 / 10 格音量条。

## 8. 沉浸歌词（AMLL player 等价对象）

> 几何/样式全部以真实 AMLL Player（amll-dev/amll-player，`@applemusic-like-lyrics/react-full`）
> 在 1600×1000（horizontal）与 800×1000（vertical）下的浏览器实测值为准；
> 布局选择与 AMLL `AutoLyricLayout` 一致：**宽 ≥ 高 → 横向，宽 < 高 → 竖向**。

### 共用（AMLL 语义）

- 歌词字号：Medium 档 `max(max(5vh, 2.5vw), 14px)`；宽 ≤ 768 时 `max(8vw, 12px)`。
- 字重 600；行高 1.2；译文/音译 0.5em、行高 1.5em、透明度 0.3；背景行 0.4 / 0.7em。
- 行内边距：左右 1em、上下 0.4em；行容器上下按 10% 高度渐隐（竖向只有顶部 10%）。
- 模糊分级：`blur = 1 + 距焦点行数`（焦点上方行 +1）；容器宽 ≤ 1024 时 ×0.8。
- 当前演唱行 wrapper 透明度 0.85（高亮组）；动态歌词非当前行由亮/暗层呈现 0.2；
  非逐词歌词非当前行 0.2。
- 缩放：非当前行 0.97（播放中）、背景行 0.75；弹簧 posY m0.9/d15/s90，scale m2/d25/s100。
- 扫光：整行共享一条 mask 前沿，软边宽默认 0.6em（与 AMLL 一致），
  可在「设置 → 播放 → 歌词」调整为 0.1–4.0em；前沿在每个词的时长内
  从上一词尾推进到本词尾，词间停顿保持不动，因此渐变带连续跨字/词，
  而不是每个词各自点亮；未开始的词保持暗层。
- 逐词浮动：每个词在自己的时长内上浮 0.05em（背景行 0.1em，`ease-out`，
  `max(1s, 词时长)`），行离场时按同一轨迹倒放。
- 强调词：非 CJK 无空白相邻词先合并成词段（YRC 常把英文词拆段），CJK 按单字
  时长判断；达标后按合并时长做逐字 stagger 缩放/左右位移/sin 浮动，辉光为
  `text-shadow 0 0 min(0.3, blur*0.3)em` 的真高斯模糊。
- 背景：动画 Mesh Gradient（BHP 网格）铺满全窗 + 全高
  `transparent 60% → rgba(0,0,0,0.102) 100%` 渐变；无顶部压暗层。
  渲染路径：光栅分辨率 = 显示区域 ÷ 「渲染分辨率除数」（1–20，默认 4），
  硬上限 200k 像素（30fps），GPU 双线性上采样到全窗；
  背景不可见时不光栅、不请求动画帧。
- 鼓点律动：播放线程按设置频段（默认 4000–10000 Hz，可自定义）计算 0..1
  包络；频段能量先减去约 0.9s 的自适应响度基线，再把正向瞬态放大，持续
  铺底的镲片/齿音不会把网格长期顶在高位。包络驱动 Mesh 网格的呼吸缩放、
  UV 旋转/推近与提亮，`set_beat_level` 在视图帧之间按 35ms 起音 / 180ms
  回落平滑（不受 30fps 光栅门控影响）；频段修改即时生效。视觉幅度另由
  「效果强度」倍率统一缩放（0–150%，默认 50%；0 只保留背景流动），
  设置路径为「设置 → 播放 → 背景律动」，持久化到 `config.json` 的
  `beat_strength`。
- 封面交叉淡出：按墙钟 420ms 推进（与显示器刷新率无关）；退场封面保持
  不透明，避免快速连切时多层半透明叠在黑色底上导致背景变黑。
- 顶部拖拽 pill：50×8、圆角 4、白 17.6%。

### 横向（宽 ≥ 高）

- 列：信息列 0.45W / 歌词列 0.55W（gap 8）；行：drag 0.12fr / thumb 40 /
  cover / music-info 0.8fr / buttom 40 / tail 0.08fr，`fr = H − 120 − cover`。
- 封面：`min(45vh, 38vw)`（H ≤ 1000；否则 50vh），无圆角、投影、居中于信息列。
- 曲目信息：`max(2vh, 1em)`（20px @1000）；曲名 500/0.9，艺人 400/0.45，
  多位艺人 `", "` 连接、末位前 `" & "`；右侧 35×35 菜单圆钮（白 8%）。
- 进度条：命中 24px / 可见 8px 圆角条（hover 展开 20px），轨道白 15%、填充白 40%；
  标签行 12.8px w500 op0.5：左当前时间、中音质 pill、右剩余时间。
- 传输：5 × 18%cover 圆钮（space-evenly），hover 白 13%；图标侧 0.26×btn、
  播放 0.37×btn。
- 音量：双喇叭图标 op0.5 + 同款滑杆。
- 底部控制行：全宽、左全屏 / 右队列·退出，40×40 圆钮 op0.45、gap 32、padding 32。
- 歌词列右 padding 8%（H > 1000 时 15%），歌词对齐封面中心（align = 封面中线 / H）。

### 竖向（宽 < 高）

- 行：drag 30 / thumb 30 / main 1fr（gap 2）。
- 小封面 6em = 96（宽 ≤ 480 时 4.5em），x = 3em、y = main_top + 1em。
- 曲目信息在封面右侧垂直居中（16px：曲名 500/0.9、艺人 0.45），菜单钮贴右缘 3em。
- 歌词铺满其余高度，对齐 `0.1 / top`；mask 仅顶部 10% 渐隐。
- 歌词打开时不显示传输控件（与 AMLL 竖向一致）；Esc 退出沉浸。

## 9. 图标与动效

- 图标全部用 `canvas + PathBuilder` 自绘（16×16 网格），不用 ▶/⏸ emoji。
- 沉浸层传输控件对齐 AMLL `MediaButton`：
  - 进入页面：全部按钮内容播放 `pressed-animation`（1 → 0.85 → 1.1 → 1，0.7s）；
    上一首/下一首同时播放双箭头合并入场（0.6s
    `cubic-bezier(0.4,1.51,0.4,1)`：左箭头滑到右箭头位置、右箭头缩小消失、
    新左箭头从左侧缩放出现；上一首镜像）。
  - 播放/暂停、shuffle、repeat 状态切换时，对应 SVG 重新挂载并回弹。
  - 音量滑杆到达 0 / 1 时，对应喇叭本体与 3 道声波按 50ms 间隔
    `1 → 1.2 → 0.85 → 1` 弹跳。
  - 动画跟随显示刷新率（300Hz 屏即 300fps），结束后完全空闲；暂停时不空转。
- 面板内其它图标 hover 即时换色；不做位移/缩放/回弹。
- 页面切换、Toast 等如后续添加，控制在 140–200ms ease-out。
- 暂停时不要每帧请求动画帧；沉浸播放时才驱动 AMLL。

## 10. 反模式

- 紫色/红色大面积铺底、渐变按钮、彩色发光。
- 除悬浮 Dock 外使用玻璃拟态 / backdrop blur / 卡片套卡片。
- 每行放真实封面墙、行内塞满按钮。
- 顶栏显示音量百分比/后端名/调试耗时。
- 用 emoji 当图标；用 marquee 滚动标题。
- 暂停后仍让装饰动画空转。
