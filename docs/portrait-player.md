# 播放页 / Dock / 均衡器 — 参考视频分析与实现说明

参考视频：`.tmp_templateVedio/bbc1ceb856e5133dda08aaccd9a7f158.mp4`
（720×1280 · 60fps · 69.2s，Salt Player 风格的 Android 播放器操作演示）

本文记录从视频中读出的交互与动画，以及 Chordial 2.0 中对应的实现。视频只作为行为参考，
实现代码、图标、配色与数据集均为本项目自有。

> 当前实现使用两套布局，但共用同一组控件：
> **布局 1** = 横向/类平板窗口且歌词可见（左播放列 + 右歌词）；
> **布局 2** = 竖屏、窄窗、强制竖屏、无歌词或用户收起歌词（居中播放列；
> 可从底栏常驻的歌词按钮打开全屏歌词）。
> 两套布局的底部控制行由同一个构建函数生成；布局 2 的次级入口统一收进
> 「…」抽屉。视频中的 Salt Player 封面态/歌词态已被这两套布局吸收，视频仍然
> 作为 Dock 动作、队列手势与均衡器编辑方式的参考。

## 1. 时间轴与观察结论

| 时间 | 画面 | 结论 |
| --- | --- | --- |
| 0.0–5.0s | 浅色专辑列表 / 专辑详情 / 底部 mini player | 点击 mini player 进入播放页 |
| 5.0–8.0s | 竖屏播放页（封面态） | 标题+艺人、大封面、当前歌词、进度条、传输键、Dock |
| 8.035s | 硬切到歌词态 | 视频里封面态 ↔ 歌词态接近硬切 |
| 8–20s | 歌词态自动滚动 | 当前行高亮、译文约 40% 透明度、上下行衰减/模糊 |
| 20.5–22.5s | 上滑进入播放队列 | 播放页上移、队列从底部进入；底部播放模式胶囊 |
| 23–27s | 横向进入「更多」页 | 播放页右移、更多页从左侧进入；更多页保留传输键 |
| 26.9s 之后 | 标题/进度/Dock 消失 | 约 3–4 秒无操作后自动隐藏，触摸后恢复 |
| 34.5–44s | 均衡器编辑 | 频响曲线、±24dB 网格、拖动控制点、频段参数 |
| 44–69s | 预设 | V4、AutoEQ、内置、个人配置四个列表 |

关键尺寸（按 720×1280 视频目测，供实现参考）：

- 封面：504×504（视口宽 70%），左边距 108（15%），圆角约 6px。
- 标题 24px/600，艺人 12px；进度条左右各 108，时间码 11px。
- 传输键：上一首/播放/下一首，图标 26–30px，行高约 66px。
- Dock：5 个 22px 图标均分内容宽度，行高约 46px。
- 歌词态：字号约 34px/600，行距 1.3，当前行位于视口约 42% 高度。

## 2. 底部控制行与「…」抽屉

### 统一控制行

两套布局都使用同一个 `immersive_bottom_row`：

`全屏`（左） ·（右）`视图选择器 ▼`

- 40px 全屏圆钮 + 一个「图标 + 文字 + 箭头」的选择器；底栏左右边界分别
  对齐播放列左缘与右侧内容列右缘（即主沉浸区边界），按钮完整落在内容区内，
  不再挂在窗口角上；
- 右下角不再有独立的「更多」按钮；更多播放选项统一由曲名/艺人行右侧圆钮
  打开抽屉；
- 选择器展开四项：`显示播放队列`、`显示歌词`、`音频详情`、`仅显示主内容`。
  前三项共用与宽屏歌词列**完全相同**的右侧内容区；「仅显示主内容」收起
  右侧内容区，播放列居中。队列不再整页替换播放页；
- 两套布局底栏与内容列同宽；按钮 40px、18px 图标、45% 静息透明度。

### 闲置自动隐藏

仅 `歌词` 与 `仅显示主内容` 两种模式启用：

- 5s 无指针移动/点击后，传输键、曲名右侧「更多」圆钮、音量条与底栏按钮
  淡出（260ms）；传输/音量行的高度一起收敛，信息行与进度条用
  `space-between` 填上空出的位置；
- 指针移动或点击立即恢复；专辑图上方小白条、专辑图、曲名/艺人、进度条、
  时间与音质标签、右侧内容（歌词/队列/详情）始终不隐藏；
- 抽屉、音质弹窗、均衡器、下拉手势与选择器展开期间不触发；
- 复用 200ms 播放状态轮询检查闲置，不另开常驻定时循环。

### 「…」抽屉

- 点击底栏「…」或曲目信息右侧的圆钮，从卡片底部滑入（240ms ease-out），
  背后压 38% 黑色遮罩，点击遮罩或右上角关闭；
- 一级页：`睡眠定时`、`均衡器`、`歌词`（沉浸层内且当前有歌词时出现，
  窄窗/强制竖屏同样可用）、`播放队列`、音频信息、参与创作的艺术家、`退出播放页`；
- `睡眠定时` 是抽屉内的二级页：`返回` + 15/30/60 分钟/关闭定时，选择后回到
  一级页并收合抽屉；
- 布局 1 / 布局 2 共用同一只抽屉，抽屉开关不改变当前布局；
- 抽屉打开时控件保持常驻，不再有自动隐藏计时。

## 3. 播放页操作逻辑

### 一套列，两种定位

`amll_player_column` 同时服务宽屏与竖屏：

```text
封面
20px
信息行（曲名 / 艺人 / 35px 菜单钮）
进度条 + 时间 / 音质
传输行（shuffle / prev / play / next / repeat）
音量行（小喇叭 / 滑杆 / 大喇叭）
```

所有行共用同一个 `column_w`，这是「没对齐」问题的根因修复：之前封面宽度与
控件宽度不同，现在封面就是列宽。

### 布局选择

`stage_split_active()` 是唯一判据：**横向窗口 + 非「仅显示主内容」** 使用
分栏布局（歌词 / 队列 / 音频详情共用右列），其余情况（竖屏、「仅显示主内容」）
使用居中播放列。视图选择器切换时共享元素走同一套 FLIP。

```text
布局 1（宽屏/类平板）                 布局 2（竖屏/无歌词）
┌──────────┬──────────────┐          ┌────────────────┐
│ 播放列   │ 歌词          │          │    播放列      │
│ (45% 区) │ (右列)        │          │   (居中)       │
│          │               │          │                │
└──────────┴──────────────┘          └────────────────┘
 底栏：全屏 · 视图选择器 ▼            底栏：全屏 · 视图选择器 ▼
```

### 宽屏（布局 1）

- 横向窗口且未选「仅显示主内容」时启用；播放器列位于窗口左侧 45% 区域，
  歌词 / 队列 / 音频详情占同一个右列；
- 选择「仅显示主内容」：整列滑到窗口中心，右列收起；
- 底栏与抽屉的歌词按钮同源：切换回「显示歌词」即可恢复右列；
- 歌词对齐封面中心（AMLL `alignPosition`），其他内容用同样的容器几何。

### 竖屏 / 窄窗 / 无歌词（布局 2）

- 默认显示封面播放页，歌词视图只作为全窗 Mesh 背景；
- 视图选择器切到「显示歌词」时打开全屏歌词：播放列让位，歌词居中（当前行
  约 42% 高度）、可点击跳转时间轴；队列/音频详情在同一右侧区域显示；
- 页面切换（播放页 ⇄ 队列）期间先隐藏歌词文字，结束后恢复，避免压在滑动的页面上；
- `open_lyrics_immersive`（Dock 的「打开沉浸歌词」）在窄窗直接落到全屏歌词；
- 播放器列水平居中，`content_w = min(82% 宽, 55% 高, 560px)`；
- 窗口过矮时先缩小封面，保证信息/进度/传输/音量至少 196px 高；
- 封面、信息、进度、传输、音量共用同一列宽；底栏与右侧内容列使用同一内容列宽；
- 横向窗口但无歌词时也走这套布局，不再单独维护「宽屏居中」分支。

### 队列与共享元素

- 队列：纵向滑入（320ms ease-out），顶部提示点击返回，行内可删除/切歌，
  底部胶囊循环切换播放模式；
- 队列页始终使用布局 2 的列宽；从布局 1 进入队列时，封面/曲名走 FLIP
  缩放到队列页头，返回时再飞回左侧歌词分栏；
- 共享元素补间使用 `layout_morph` 的 `ease_out_quint`，布局 1↔2 的歌词切换
  也复用同一条补间。

### Dock⇄全屏共享布局

沉浸层不再是「淡入一块全屏页面」，而是以底部 Dock 为第一帧的共享布局动画：

- 进入时 Dock 的条状矩形先放大成卡片，卡片内再逐渐显出完整播放页；同时
  共享封面/曲名/艺人从 Dock 内的小元素连续飞到沉浸页对应位置（`layout_morph`
  的 `dock_rect` / `dock_geometry` + `render_shared_stage_colored`）；
- 卡片本身用解析弹簧驱动（与 `chordial-amll-gpui::spring` 同一套物理语义）；
- 靠近 Dock 时卡片底色/边框/文字颜色过渡回 Dock 的玻璃底与主题色，
  最后一帧与真实 Dock 一致，退出时不会闪黑或重叠两层文字；
- 背景 Mesh 按「卡片绝对矩形」绘制，卡片下移/缩小时不会在底部留下黑边。

### 顶部下拉关闭

宽屏与竖屏的沉浸页共用顶部 pill 把手（`sheet_drag.rs`）：

- 按住 pill 及其周围的空白区向下拖动，卡片跟手向 Dock 收缩并露出背后的主面板；
- 松手时位移超过窗口高度 18%，或位移 > 48px 且甩动速度 > 720px/s，则弹簧收进
  Dock 后退出沉浸层；否则弹簧回弹到全屏（轻微过冲）；
- 关闭/展开都用解析弹簧，最长 0.9s 强制收敛；动画期间才做双层渲染，
  结束即停止，不留下常驻开销；
- 队列页的页面内容盖住把手命中区，因此下拉关闭只在播放页生效，
  子页仍使用原有手势与返回提示；「…」抽屉作为覆盖层同样不参与下拉手势。

## 4. 均衡器

均衡器有两套随窗口几何切换的布局，状态、绘制与 DSP 完全共用：
`eq_layout()` 在「强制竖屏 / 宽 < 820 / 高 > 宽」时选择紧凑布局，否则使用桌面布局。

### 桌面 Studio 控制台

- 居中浮层（最大 1180×820），背景压暗；点击浮层外关闭，点击浮层内不会误关；
- 左侧工作区导航：编辑器 / V4 / AutoEQ / 内置 / 个人（带数量徽标），
  底部显示当前配置与输入增益摘要；
- 中间为频响主画布 + 频段推子排：单击空白添加频段，拖动节点改频率/增益，
  右键删除；推子以 0dB 为中点，上下拖动改增益，末位有添加键；
- 右侧检视器：频率/增益大读数、滤波器类型五等分、频率/增益/Q 滑杆、
  单频段启用/旁路与移除；输入/输出增益固定在检视器底部；
- 预设页展开为「列表 + 预览」：单击只预览（右侧实时曲线、滤波器与最大提升/衰减），
  点「应用此预设」才生效；预览高亮与当前使用标记分离；
- 底部状态栏显示实时/旁路、参数热更新说明与 Esc。

### 紧凑触控布局

- 全屏渐变，内容列最大 560px 居中；顶部返回、当前配置/频段数与总开关；
- 频响画布是主操作区，使用更大的控制点命中半径与更少的坐标标签；
- 横向频段芯片：序号、频率、增益或滤波器类型、启用点；末位为添加；
  点选芯片后，参数进入下方检视器；
- 底部检视器：大号频率/增益、频段启用/旁路、类型五等分、频率/增益/Q 滑杆、
  输入/输出增益与「另存为个人预设」；
- 五个 Tab 固定在底部，内容独立滚动；预设列表单击立即应用。

### 图形与参数

- 20Hz–20kHz 对数横轴、+24…−24dB 纵轴、6dB 网格；1kHz 与 0dB 主网格加强；
- 曲线与播放线程使用**同一组 biquad 系数**计算（`EqSettings::response_db`）；
- 旁路（总开关关闭）时曲线与控制点转为中性灰，仍可编辑；
- 频率（对数滑杆）、增益（双极性滑杆，0dB 居中）、品质因数 Q（0.1…12，对数滑杆）；
- 最多 32 个频段；输入/输出增益 −24…+24dB。

### 预设页

五个入口在桌面端是左侧导航、紧凑端是底栏 Tab：

1. **编辑器**：曲线 + 推子/芯片 + 检视器；
2. **V4**：4 条风格配置；
3. **AutoEQ**：从 `jaakkopasanen/AutoEq` 仓库同步的 6000+ 条耳机配置
   （搜索 + 头戴式/入耳式/耳塞式筛选）；
4. **内置**：12 条内置预设；
5. **个人**：`另存为` 保存的配置，可预览/应用/删除。

> AutoEQ 索引来自仓库的 `results/README.md`（约 500 KB），单个型号的
> `ParametricEQ.txt` 在首次预览/应用时按需下载；索引与曲线都缓存在配置目录旁的
> `autoeq/`，之后离线可用。GitHub raw 不可用时自动走 jsDelivr 镜像。

### DSP

`crates/chordal-player/src/equalizer.rs`：

- RBJ 峰值/低架/高架/低通/高通双二阶系数；
- 每声道独立的 Direct Form II Transposed 状态；
- 系数在 64 帧粒度向目标值收敛，输入/输出增益 5ms 一阶平滑，避免拖动滑杆时的
  zipper noise；
- 播放线程在写设备前处理样本（EQ → 音量 → 输出），参数热更新，不中断当前曲目；
- 配置写入 `config.json` 的 `equalizer` 与 `eq_saved_presets`，400ms 防抖落盘。

## 6. 有意的取舍

- 视频是触屏手势；桌面端用鼠标按住/拖拽表达同一套手势，右键/「⋮」等价于长按菜单。
- 布局不再按「宽屏一套、竖屏一套」分别维护：布局 1 只在歌词可见时存在，
  其余情况一律使用布局 2，避免两份播放页漂移。
- 两套布局的底栏共用同一个构建函数；布局 2 的直接入口只保留核心项，
  定时/均衡器/歌词等次级入口进入抽屉。
- 队列页的封面与曲名使用共享元素 FLIP，页面本身仍然整页滑入，二者叠加。
- 个人配置的「另存为」使用自动命名（自定义 N），没有额外弹窗输入。

## 7. 手机壳（单窗口竖屏）操作补充

参考视频的第二段操作演示补上了单列界面里的日常交互，代码位于
`crates/chordal-ui/src/phone_gesture.rs` 与 `app.rs` 的手机壳渲染段。

### mini player ⇄ 播放页

- 曲库页底部常驻一级导航（曲库 / 队列 / 搜索 / 设置）；mini player 悬浮在
  导航条上方（封面 / 曲名 / 播放 / 队列 / 更多），
  底边有一条 2px 播放进度；列表底部预留 92px，最后一行不会被遮住。
- 点击 mini player 或从它向上拖：播放页以卡片形式从底部弹性展开，
  背后压暗曲库页；向下拖顶部把手（或点左上角「∨」/Esc）收起。
- 拖拽卡片跟手改变高度与圆角，松手按 24% 行程或 560px/s 甩动决定去留，
  使用解析弹簧收尾（`SheetSwipe`）。
- 播放页与 mini player 共用同一套 `Cell`；页面切换只改 `phone_page`，
  `lyric_view` 的背景只在播放页占用。

### 封面 ⇄ 歌词

- 在封面上向左拖超过 24% 宽度（或 560px/s）进入歌词页；从歌词页左缘
  向右拖返回播放页。拖动过程中封面/播放列跟手横移，松手后提交或回弹。
- 封面单击仍然直接打开歌词页；横滑过的松手不会误触单击。

### 曲目行菜单与多选

- 桌面右键、行尾「⋮」或 mini player 的「…」都会打开同一只曲目菜单：
  播放/暂停、下一首播放、加入队列、查看专辑、查看歌手、多选、
  从队列移除。
- 手机长按曲目行 480ms 进入多选；顶部栏替换为「返回 / 已选 N 首 / 全选」，
  底部是批量「播放 / 下一首 / 加入队列 / 移出队列」操作条。
- 多选只作用于进入时的列表快照，滚动或切页不会误删到别的行。

### 播放队列

- 队列是曲库页的 `LibraryFilter::Queue` 视图，不再重复搜索框；页头提供
  播放全部、播放模式胶囊（点击循环）与清除。
- 行首序号是拖拽把手：上下拖动实时高亮目标行，松手后移动队列项并
  同步修正 `queue_pos`；拖拽结束的 300ms 内吞掉 click，避免误播。
- 队列行的「−」与曲目菜单里的「从播放队列移除」共用 `remove_queue_at`。

### 抽屉补充

- 手机「…」抽屉新增「出自专辑」「沉浸播放页」；音频信息与参与创作的
  艺术家卡片保留，专辑/歌手可直接跳转。
- Esc 的收敛顺序：音质弹窗 → 设置 → 抽屉 → 曲目菜单 → 多选 →
  收起播放页 → 展开播放页。
